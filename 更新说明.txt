三、Termux 手机部署脚本（提交 fc19179 … 87ca523，共 7 个）
----------------------------------------

deploy/termux/ 下 9 个文件：

  deploy.sh      一键部署（新手机一行命令到浏览器自动打开）
  setup.sh       装包 / pnpm@10.34.5 / initdb / 探 socket 与用户名 / 迁移 / 构建
  doctor.sh      只读预检（包、库、socket、密钥、端口、磁盘内存）
  start.sh       起 postgres / api / worker / 前端，起完自动开浏览器
  stop.sh        停进程 + 按 /proc 清孤儿进程
  pair.sh        生成一次性配对码并打印链接（15 分钟有效）
  backup-db.sh   pg_dump 备份 + sha256
  env.example    环境变量模板
  README.md      完整 runbook

踩坑修出来的适配：

  * pnpm 精确装 packageManager 钉的 10.34.5
    （修 @pnpm/exe.android-arm64 不在 lockfile 导致的安装失败）
  * postgres socket 目录自动探测（Termux 用 $PREFIX/tmp，不是 Debian 的
    /var/run/postgresql）
  * DATABASE_URL 显式带 user=（node-postgres 只读 process.env.USER，
    Termux 默认不设）
  * .env 重写用纯 bash 逐行改（sed 的 & 展开会写坏 URL）
  * 孤儿进程清理（重装仓库后旧进程揣旧 token 报 401、占端口报
    EADDRINUSE）
  * 新装 Termux 先 apt update && apt full-upgrade（libcurl 符号缺失）
